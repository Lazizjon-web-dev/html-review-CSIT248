Forms contain form elements like input fields, text areas, buttons, and checkboxes that allow users to submit data. </div> <table> <thead> <tr> <th>Attribute</th> <th>Role</th> </tr> </thead> <tbody> <tr> <td><code>action</code></td> <td>Specifies where to send the form data when submitted</td> </tr> <tr> <td><code>method</code></td> <td>Specifies the HTTP method (GET or POST)</td> </tr> <tr> <td><code>enctype</code></td> <td>Specifies how form data should be encoded</td> </tr> </tbody> </table> <div class="example-container"> <div class="example-code"> <pre><code>&lt;form action="/submit" method="POST"> &lt;label for="name">Name:&lt;/label> &lt;input type="text" id="name" name="name"> &lt;button type="submit">Submit&lt;/button> &lt;/form></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <form style="display: flex; flex-direction: column; gap: 10px;"> <div> <label for="name1">Name:</label> <input type="text" id="name1" name="name" style="margin-left: 10px;"> </div> <button type="submit" style="width: fit-content; padding: 8px 16px; background-color: #667eea; color: white; border: none; border-radius: 5px; cursor: pointer;">Submit</button> </form> </div> </div> <!-- Input Tag --> <h3>&lt;input&gt; Tag</h3> <div class="definition"> The <code>&lt;input&gt;</code> tag is used to create interactive form controls. It is a self-closing tag that supports various types like text, email, password, number, checkbox, and radio buttons. </div> <table> <thead> <tr> <th>Attribute</th> <th>Role</th> </tr> </thead> <tbody> <tr> <td><code>type</code></td> <td>Specifies the type of input (text, email, password, number, etc.)</td> </tr> <tr> <td><code>name</code></td> <td>Specifies the name of the input (used for form submission)</td> </tr> <tr> <td><code>placeholder</code></td> <td>Shows hint text when the field is empty</td> </tr> <tr> <td><code>required</code></td> <td>Makes the field mandatory</td> </tr> </tbody> </table> <div class="example-container"> <div class="example-code"> <pre><code>&lt;input type="email" name="email" placeholder="Enter your email" required></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <input type="email" name="email" placeholder="Enter your email" required style="padding: 8px; font-size: 1rem;"> </div> </div> <!-- Label Tag --> <h3>&lt;label&gt; Tag</h3> <div class="definition"> The <code>&lt;label&gt;</code> tag provides a label for form inputs. It improves usability by making form fields more accessible and clickable, especially for checkboxes and radio buttons. </div> <table> <thead> <tr> <th>Attribute</th> <th>Role</th> </tr> </thead> <tbody> <tr> <td><code>for</code></td> <td>Specifies the ID of the form element that the label belongs to</td> </tr> </tbody> </table> <div class="example-container"> <div class="example-code"> <pre><code>&lt;label for="email">Email:&lt;/label> &lt;input type="email" id="email" name="email"></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <label for="email2" style="margin-right: 10px;">Email:</label> <input type="email" id="email2" name="email" style="padding: 8px; font-size: 1rem;"> </div> </div> <!-- Textarea Tag --> <h3>&lt;textarea&gt; Tag</h3> <div class="definition"> The <code>&lt;textarea&gt;</code> tag creates a multi-line text input field. It allows users to enter longer amounts of text such as comments, messages, or descriptions. </div> <table> <thead> <tr> <th>Attribute</th> <th>Role</th> </tr> </thead> <tbody> <tr> <td><code>rows</code></td> <td>Specifies the number of visible text lines</td> </tr> <tr> <td><code>cols</code></td> <td>Specifies the visible width in characters</td> </tr> <tr> <td><code>placeholder</code></td> <td>Shows hint text when the field is empty</td> </tr> </tbody> </table> <div class="example-container"> <div class="example-code"> <pre><code>&lt;textarea rows="4" cols="50" placeholder="Enter your message">&lt;/textarea></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <textarea rows="4" cols="50" placeholder="Enter your message" style="padding: 8px; font-size: 1rem; font-family: 'Courier New', monospace;"></textarea> </div> </div> <!-- Button Tag --> <h3>&lt;button&gt; Tag</h3> <div class="definition"> The <code>&lt;button&gt;</code> tag creates a clickable button that can perform various actions such as submitting forms or triggering JavaScript functions. </div> <table> <thead> <tr> <th>Attribute</th> <th>Role</th> </tr> </thead> <tbody> <tr> <td><code>type</code></td> <td>Specifies the button type (submit, reset, button)</td> </tr> <tr> <td><code>name</code></td> <td>Specifies the name of the button</td> </tr> <tr> <td><code>value</code></td> <td>Specifies the value sent when the button is clicked</td> </tr> </tbody> </table> <div class="example-container"> <div class="example-code"> <pre><code>&lt;button type="submit">Submit&lt;/button> &lt;button type="reset">Reset&lt;/button></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <button type="submit" style="padding: 8px 16px; color: white; border: none; border-radius: 5px; cursor: pointer;">Reset</button> </div> </div> <!-- Select and Option Tags --> <h3>&lt;select&gt; and &lt;option&gt; Tags</h3> <div class="definition"> The <code>&lt;select&gt;</code> tag creates a dropdown list, and the <code>&lt;option&gt;</code> tag defines the selectable options within that list. </div> <table> <thead> <tr> <th>Attribute</th> <th>Role</th> </tr> </thead> <tbody> <tr> <td><code>name</code></td> <td>Specifies the name of the select list</td> </tr> <tr> <td><code>multiple</code></td> <td>Allows multiple selections</td> </tr> <tr> <td><code>selected</code></td> <td>(option) Pre-selects an option</td> </tr> </tbody> </table> <div class="example-container"> <div class="example-code"> <pre><code>&lt;select name="country"> &lt;option value="usa">USA&lt;/option> &lt;option value="canada">Canada&lt;/option> &lt;option value="mexico" selected>Mexico&lt;/option> &lt;/select></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <select name="country" style="padding: 8px;
