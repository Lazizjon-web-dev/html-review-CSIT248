List items inside an unordered list are displayed with bullet points by default. </div> <table> <thead> <tr> <th>Attribute</th> <th>Role</th> </tr> </thead> <tbody> <tr> <td><code>type</code></td> <td>Specifies the bullet point style (disc, circle, square)</td> </tr> </tbody> </table> <div class="example-container"> <div class="example-code"> <pre><code>&lt;ul> &lt;li>Apple&lt;/li> &lt;li>Banana&lt;/li> &lt;li>Orange&lt;/li> &lt;/ul></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <ul> <li>Apple</li> <li>Banana</li> <li>Orange</li> </ul> </div> </div> <!-- Ordered List Tag --> <h3>&lt;ol&gt; Tag (Ordered List)</h3> <div class="definition"> The <code>&lt;ol&gt;</code> tag creates an ordered (numbered) list. List items in an ordered list are displayed with numbers or letters depending on the type attribute. </div> <table> <thead> <tr> <th>Attribute</th> <th>Role</th> </tr> </thead> <tbody> <tr> <td><code>type</code></td> <td>Specifies numbering style (1, a, A, i, I)</td> </tr> <tr> <td><code>start</code></td> <td>Specifies the starting number of the list</td> </tr> <tr> <td><code>reversed</code></td> <td>Reverses the order of list items (descending)</td> </tr> </tbody> </table> <div class="example-container"> <div class="example-code"> <pre><code>&lt;ol> &lt;li>First step&lt;/li> &lt;li>Second step&lt;/li> &lt;li>Third step&lt;/li> &lt;/ol></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <ol> <li>First step</li> <li>Second step</li> <li>Third step</li> </ol> </div> </div> <!-- List Item Tag --> <h3>&lt;li&gt; Tag (List Item)</h3> <div class="definition"> The <code>&lt;li&gt;</code> tag defines a single item within a list. It can only be used inside <code>&lt;ul&gt;</code>, <code>&lt;ol&gt;</code>, or <code>&lt;menu&gt;</code> elements. </div> <table> <thead> <tr> <th>Attribute</th> <th>Role</th> </tr> </thead> <tbody> <tr> <td><code>value</code></td> <td>Specifies the numeric value for an item in an ordered list</td> </tr> </tbody> </table> <div class="example-container"> <div class="example-code"> <pre><code>&lt;ol> &lt;li value="10">Item ten&lt;/li> &lt;li>Item eleven&lt;/li> &lt;li>Item twelve&lt;/li> &lt;/ol></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <ol> <li value="10">Item ten</li> <li>Item eleven</li> <li>Item twelve</li> </ol> </div> </div> <!-- Definition List Tag --> <h3>&lt;dl&gt; Tag (Definition List)</h3> <div class="definition"> The <code>&lt;dl&gt;</code> tag creates a definition list, which consists of terms and their definitions. It is useful for glossaries, dictionaries, and term-definition pairs. </div> <table> <thead> <tr> <th>Attribute</th> <th>Role</th> </tr> </thead> <tbody> <tr> <td>N/A</td> <td>The <code>&lt;dl&gt;</code> tag has no specific attributes beyond global attributes</td> </tr> </tbody> </table> <div class="example-container"> <div class="example-code"> <pre><code>&lt;dl> &lt;dt>HTML&lt;/dt> &lt;dd>HyperText Markup Language&lt;/dd> &lt;dt>CSS&lt;/dt> &lt;dd>Cascading Style Sheets&lt;/dd> &lt;/dl></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <dl> <dt>HTML</dt> <dd>HyperText Markup Language</dd> <dt>CSS</dt> <dd>Cascading Style Sheets</dd> </dl> </div> </div> <!-- Definition Term Tag --> <h3>&lt;dt&gt; and &lt;dd&gt; Tags</h3> <div class="definition"> The <code>&lt;dt&gt;</code> tag defines a term in a definition list, and the <code>&lt;dd&gt;</code> tag provides the definition for that term. These tags must be used inside a <code>&lt;dl&gt;</code> element. </div> <table> <thead> <tr> <th>Attribute</th> <th>Role</th> </tr> </thead> <tbody> <tr> <td>N/A</td> <td>Both tags have no specific attributes beyond global attributes</td> </tr> </tbody> </table> <div class="example-container"> <div class="example-code"> <pre><code>&lt;dl> &lt;dt>Web Browser&lt;/dt> &lt;dd>Software that displays web pages&lt;/dd> &lt;/dl></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <dl> <dt>Web Browser</dt> <dd>Software that displays web pages</dd> </dl> </div> </div> </div> </main> <footer> <p><strong>HTML Review Website</strong></p> <p>A learning resource for HTML fundamentals</p> <p><small>&copy; 2024 Web Development Lab</small></p> </footer> </body> </html>
