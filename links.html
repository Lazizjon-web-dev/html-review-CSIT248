It is one of the most fundamental tags in HTML and enables navigation across the web. </div> <table> <thead> <tr> <th>Attribute</th> <th>Role</th> </tr> </thead> <tbody> <tr> <td><code>href</code></td> <td>Specifies the URL of the page the link goes to</td> </tr> <tr> <td><code>target</code></td> <td>Specifies where to open the link (e.g., _blank for new window)</td> </tr> <tr> <td><code>title</code></td> <td>Specifies extra information about the link (shown on hover)</td> </tr> </tbody> </table> <div class="example-container"> <div class="example-code"> <pre><code>&lt;a href="https://example.com" target="_blank">Visit Example&lt;/a></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <a href="https://example.com" target="_blank">Visit Example</a> </div> </div> <!-- Image Tag --> <h3>&lt;img&gt; Tag (Image)</h3> <div class="definition"> The <code>&lt;img&gt;</code> tag embeds an image in the HTML document. It is a self-closing tag that requires a source (src) attribute to specify the image file. </div> <table> <thead> <tr> <th>Attribute</th> <th>Role</th> </tr> </thead> <tbody> <tr> <td><code>src</code></td> <td>Specifies the URL or path to the image file (required)</td> </tr> <tr> <td><code>alt</code></td> <td>Provides alternative text if the image cannot be loaded</td> </tr> <tr> <td><code>width</code></td> <td>Specifies the width of the image in pixels</td> </tr> <tr> <td><code>height</code></td> <td>Specifies the height of the image in pixels</td> </tr> </tbody> </table> <div class="example-container"> <div class="example-code"> <pre><code>&lt;img src="image.jpg" alt="Description of image" width="300" height="200"></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <p><em>(Image would appear here if the file existed)</em></p> </div> </div> <!-- Audio Tag --> <h3>&lt;audio&gt; Tag</h3> <div class="definition"> The <code>&lt;audio&gt;</code> tag is used to embed audio files in web pages. It supports multiple audio formats and provides built-in playback controls like play, pause, and volume adjustment. </div> <table> <thead> <tr> <th>Attribute</th> <th>Role</th> </tr> </thead> <tbody> <tr> <td><code>src</code></td> <td>Specifies the URL of the audio file</td> </tr> <tr> <td><code>controls</code></td> <td>Shows play, pause, and volume controls</td> </tr> <tr> <td><code>autoplay</code></td> <td>Audio starts playing automatically when the page loads</td> </tr> <tr> <td><code>loop</code></td> <td>Audio restarts from the beginning after reaching the end</td> </tr> </tbody> </table> <div class="example-container"> <div class="example-code"> <pre><code>&lt;audio controls> &lt;source src="audio.mp3" type="audio/mpeg"> Your browser does not support audio. &lt;/audio></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <p><em>(Audio player would appear here if the file existed)</em></p> </div> </div> <!-- Video Tag --> <h3>&lt;video&gt; Tag</h3> <div class="definition"> The <code>&lt;video&gt;</code> tag is used to embed video files in web pages. It supports multiple video formats and provides playback controls similar to the audio tag. </div> <table> <thead> <tr> <th>Attribute</th> <th>Role</th> </tr> </thead> <tbody> <tr> <td><code>src</code></td> <td>Specifies the URL of the video file</td> </tr> <tr> <td><code>width</code></td> <td>Specifies the width of the video player in pixels</td> </tr> <tr> <td><code>height</code></td> <td>Specifies the height of the video player in pixels</td> </tr> <tr> <td><code>controls</code></td> <td>Shows play, pause, and volume controls</td> </tr> </tbody> </table> <div class="example-container"> <div class="example-code"> <pre><code>&lt;video width="400" height="300" controls> &lt;source src="video.mp4" type="video/mp4"> Your browser does not support video. &lt;/video></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <p><em>(Video player would appear here if the file existed)</em></p> </div> </div> <!-- Source Tag --> <h3>&lt;source&gt; Tag</h3> <div class="definition"> The <code>&lt;source&gt;</code> tag specifies multiple media resources for <code>&lt;video&gt;</code> or <code>&lt;audio&gt;</code> elements. This allows the browser to choose a compatible format. </div> <table> <thead> <tr> <th>Attribute</th> <th>Role</th> </tr> </thead> <tbody> <tr> <td><code>src</code></td> <td>Specifies the URL of the media file (required)</td> </tr> <tr> <td><code>type</code></td> <td>Specifies the MIME type of the media file</td> </tr> </tbody> </table> <div class="example-container"> <div class="example-code"> <pre><code>&lt;video controls> &lt;source src="video.mp4" type="video/mp4"> &lt;source src="video.webm" type="video/webm"> &lt;/video></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <p><em>(Video player would appear here if the file existed)</em></p> </div> </div> </div> </main> <footer> <p><strong>HTML Review Website</strong></p> <p>A learning resource for HTML fundamentals</p> <p><small>&copy; 2024 Web Development Lab</small></p> </footer> </body> </html>
