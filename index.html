Welcome to HTML Review

This website provides a comprehensive review of the most important HTML tags used in web development. Each page focuses on a specific category of tags and demonstrates their proper usage with real examples.

HTML Document Structure

Every HTML document follows a standard structure that defines the basic framework for web pages. The &lt;!DOCTYPE html&gt; declaration tells the browser this is an HTML5 document. The &lt;html&gt; element is the root container for all other elements.

Common HTML Tags Overview

Tag Purpose
&lt;h1&gt; ... &lt;h6&gt; Headings (from largest to smallest)
&lt;p&gt; Paragraphs of text
&lt;a&gt; Hyperlinks to other pages or resources
&lt;img&gt; Embedded images
&lt;ul&gt;, &lt;ol&gt; Unordered and ordered lists
&lt;table&gt; Display data in rows and columns
&lt;form&gt; Collect user input

Basic HTML Document Example

&lt;!DOCTYPE html&gt;
&lt;html lang="en"&gt;
&lt;head&gt;
    &lt;meta charset="UTF-8"&gt;
    &lt;title>Page Title&lt;/title>
&lt;/head&gt;
&lt;body&gt;
    &lt;h1>Hello World&lt;/h1>
    &lt;p>This is a paragraph.&lt;/p>
&lt;/body&gt;
&lt;/html&gt;

Rendered Result:

Hello World

This is a paragraph.
