<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>HTML Review - Metadata</title> <link rel="stylesheet" href="css/style.css"> </head> <body> <header> <h1>HTML Review Website</h1> <p>A comprehensive guide to HTML tags, their attributes, and usage examples</p> </header> <nav> <ul> <li><a href="index.html">Home</a></li> <li><a href="text.html">Text Tags</a></li> <li><a href="links.html">Links & Media</a></li> <li><a href="lists.html">Lists</a></li> <li><a href="tables.html">Tables</a></li> <li><a href="forms.html">Forms</a></li> <li><a href="media.html">Multimedia</a></li> <li><a href="semantic.html">Semantic Tags</a></li> <li><a href="metadata.html" class="active">Metadata</a></li> </ul> </nav> <main> <div class="tag-section"> <h2>Metadata Tags</h2> <div class="definition"> Metadata tags are used in the <code>&lt;head&gt;</code> section of an HTML document to provide information about the page that is not displayed in the browser but is important for browsers, search engines, and other services. </div> <!-- Meta Tag --> <h3>&lt;meta&gt; Tag</h3> <div class="definition"> The <code>&lt;meta&gt;</code> tag defines metadata about an HTML document. Metadata is information about data that is used by the browser, search engines, and other web services. It is a self-closing tag. </div> <table> <thead> <tr> <th>Attribute</th> <th>Role</th> </tr> </thead> <tbody> <tr> <td><code>charset</code></td> <td>Specifies the character encoding (e.g., UTF-8)</td> </tr> <tr> <td><code>name</code></td> <td>Specifies the name of the metadata</td> </tr> <tr> <td><code>content</code></td> <td>Specifies the value of the metadata</td> </tr> <tr> <td><code>http-equiv</code></td> <td>Provides an HTTP header for the information</td> </tr> </tbody> </table> <div class="example-container"> <div class="example-code"> <pre><code>&lt;meta charset="UTF-8"> &lt;meta name="viewport" content="width=device-width, initial-scale=1.0"> &lt;meta name="description" content="Page description"> &lt;meta name="keywords" content="html, css, web"></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <p><em>Meta tags are not visible on the page but are used by browsers and search engines.</em></p> </div> </div> <!-- Title Tag --> <h3>&lt;title&gt; Tag</h3> <div class="definition"> The <code>&lt;title&gt;</code> tag defines the title of the HTML document. The title appears in the browser tab and is important for SEO (Search Engine Optimization) and user experience. </div> <table> <thead> <tr> <th>Attribute</th> <th>Role</th> </tr> </thead> <tbody> <tr> <td>N/A</td> <td>The <code>&lt;title&gt;</code> tag has no specific attributes beyond global attributes</td> </tr> </tbody> </table> <div class="example-container"> <div class="example-code"> <pre><code>&lt;title>My Awesome Website - Home Page&lt;/title></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <p><em>The title appears in the browser tab at the top of the window.</em></p> </div> </div> <!-- Link Tag --> <h3>&lt;link&gt; Tag</h3> <div class="definition"> The <code>&lt;link&gt;</code> tag defines the relationship between the current HTML document and external resources such as stylesheets, favicons, and other linked files. It is a self-closing tag. </div> <table> <thead> <tr> <th>Attribute</th> <th>Role</th> </tr> </thead> <tbody> <tr> <td><code>rel</code></td> <td>Specifies the relationship (e.g., stylesheet, icon)</td> </tr> <tr> <td><code>href</code></td> <td>Specifies the URL of the linked resource</td> </tr> <tr> <td><code>type</code></td> <td>Specifies the MIME type of the resource</td> </tr> </tbody> </table> <div class="example-container"> <div class="example-code"> <pre><code>&lt;link rel="stylesheet" href="style.css"> &lt;link rel="icon" href="favicon.ico"> &lt;link rel="preconnect" href="https://fonts.googleapis.com"></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <p><em>Link tags connect external resources but don't display visible content.</em></p> </div> </div> <!-- Style Tag --> <h3>&lt;style&gt; Tag</h3> <div class="definition"> The <code>&lt;style&gt;</code> tag is used to embed CSS styles directly into an HTML document. While external stylesheets are preferred, this tag can be useful for page-specific styles. </div> <table> <thead> <tr> <th>Attribute</th> <th>Role</th> </tr> </thead> <tbody> <tr> <td><code>type</code></td> <td>Specifies the MIME type (usually text/css)</td> </tr> <tr> <td><code>media</code></td> <td>Specifies when the style applies (e.g., screen, print)</td> </tr> </tbody> </table> <div class="example-container"> <div class="example-code"> <pre><code>&lt;style type="text/css"> h1 { color: blue; font-size: 2em; } &lt;/style></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <p><em>Styles defined in the style tag affect the appearance of HTML elements.</em></p> </div> </div> <!-- Script Tag --> <h3>&lt;script&gt; Tag</h3> <div class="definition"> The <code>&lt;script&gt;</code> tag is used to embed JavaScript code or link to external JavaScript files. JavaScript provides interactivity and dynamic behavior to web pages. </div> <table> <thead> <tr> <th>Attribute</th> <th>Role</th> </tr> </thead> <tbody> <tr> <td><code>src</code></td> <td>Specifies the URL of an external JavaScript file</td> </tr> <tr> <td><code>type</code></td> <td>Specifies the MIME type (usually text/javascript)</td> </tr> <tr> <td><code>async</code></td> <td>Script executes asynchronously while page loads</td> </tr> <tr> <td><code>defer</code></td> <td>Script executes after page finishes loading</td> </tr> </tbody> </table> <div class="example-container"> <div class="example-code"> <pre><code>&lt;script src="script.js">&lt;/script> &lt;script type="text/javascript"> console.log('Hello, World!'); alert('JavaScript is running!'); &lt;/script></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <p><em>Scripts can provide dynamic functionality and interactivity to the page.</em></p> </div> </div> <!-- Base Tag --> <h3>&lt;base&gt; Tag</h3> <div class="definition"> The <code>&lt;base&gt;</code> tag specifies the base URL and target for all relative URLs in the document. It must be placed in the <code>&lt;head&gt;</code> section. It is a self-closing tag. </div> <table> <thead> <tr> <th>Attribute</th> <th>Role</th> </tr> </thead> <tbody> <tr> <td><code>href</code></td> <td>Specifies the base URL for relative URLs</td> </tr> <tr> <td><code>target</code></td> <td>Specifies default target for links (_self, _blank, _parent, _top)</td> </tr> </tbody> </table> <div class="example-container"> <div class="example-code"> <pre><code>&lt;base href="https://example.com/" target="_blank"></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <p><em>Base tag sets the foundation URL for all relative links on the page.</em></p> </div> </div> <!-- Complete Head Example --> <h3>Complete Example: Full HTML <code>&lt;head&gt;</code> Section</h3> <div class="example-container"> <div class="example-code"> <pre><code>&lt;!DOCTYPE html> &lt;html lang="en"> &lt;head> &lt;meta charset="UTF-8"> &lt;meta name="viewport" content="width=device-width, initial-scale=1.0"> &lt;meta name="description" content="Page description for search engines"> &lt;meta name="keywords" content="html, css, javascript"> &lt;title>My Website - Home Page&lt;/title> &lt;link rel="stylesheet" href="style.css"> &lt;link rel="icon" href="favicon.ico"> &lt;base href="https://example.com/"> &lt;/head> &lt;body> &lt;!-- Page content here --> &lt;/body> &lt;/html></code></pre> </div> <div class="example-result"> <h4>Rendered Result:</h4> <p><em>The head section contains all metadata and doesn't display on the page but is essential for proper document structure and SEO.</em></p> </div> </div> </div> </main> <footer> <p><strong>HTML Review Website</strong></p> <p>A learning resource for HTML fundamentals</p> <p><small>&copy; 2024 Web Development Lab</small></p> </footer> </body> </html>
